# pi-auto-compaction v1.2.1

**First public GitHub Release · 2026-11-07**

Source-available under `UNLICENSED`. This is not an npm publication and does not change the license.

## Highlights

- Configurable summarizer selection with primary and fallback models, `/compaction`, settings file, environment variables, and hot reload.
- Scrollable and searchable model picker for long model lists.
- Per-model compaction policies, `doctor` diagnostics, allowlisted local telemetry, and multi-tier fallback to native Pi compaction.
- Transactional install, update, adoption, and source rollback under immutable `releases/<sha256>` directories.
- Bilingual English/Spanish documentation, agent installation contract, skill, contribution guide, and security policy.
- Official repository moved to https://github.com/wilkin-barban/pi-auto-compaction.

## Install

Requirements: Node.js `>=22.19.0` and Pi, gentle-shell, or herdr.

Clone the repository or download the source archive from this release:

```bash
git clone https://github.com/wilkin-barban/pi-auto-compaction.git "$HOME/proyectos/pi-auto-compaction"
cd "$HOME/proyectos/pi-auto-compaction"
npm ci --ignore-scripts
npm test
```

Then follow the [installation guide](https://github.com/wilkin-barban/pi-auto-compaction/blob/main/docs/en/installation.md) or the [guía de instalación](https://github.com/wilkin-barban/pi-auto-compaction/blob/main/docs/es/instalacion.md).
